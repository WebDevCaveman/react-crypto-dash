# React Crypto Dash

Dashboard kryptowalut na danych z CoinGecko — lista monet z filtrowaniem i sortowaniem,
strona szczegółów z wykresem 7-dniowym (Chart.js, ładowany leniwie).

Stack: React 19, React Router 7, Vite, Tailwind CSS 4, Chart.js.

## Uruchomienie

```bash
npm install
cp .env.example .env
npm run dev
```

## Skrypty

- `npm run dev` — serwer deweloperski
- `npm run build` — build produkcyjny
- `npm run preview` — podgląd builda
- `npm run lint` — ESLint
